# Sales Data Visualization Project

## Contents
- `Sales_Data_Visualization_Practice.ipynb`: Jupyter notebook with code and observations
- `sales_data.csv`: illustrative monthly sales dataset
- `monthly_sales_bar_chart.png`: bar chart
- `monthly_sales_line_chart.png`: line chart
- `Project_Report_Pranjal_Jain.pdf`: project report

## Run
Install packages using `pip install -r requirements.txt`, then open the notebook in Jupyter Notebook or VS Code and run cells in order.

Note: The sales values are sample data created for this educational project, not real company data.
